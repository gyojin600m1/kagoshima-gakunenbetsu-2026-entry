# 第33回 小学生学年別選手権水泳競技大会 エントリー確認（非公式・個人作成）

2026年9月13日(日)／鹿児島市鴨池公園水泳プール（屋内 50m×10レーン・水深1.5m）

`index.html` 1ファイルだけで動く。fetch は Abacus の閲覧カウンターのみで、`file://` でも中身は全部見られる。

## 画面

6タブ：選手／種目／日程／リレー／組・レーン／当日プラン

- 名前はひらがなでも探せる（公式の半角カナを検索用に正規化。カナは画面にも表示）
- 男女色分け（青 `#1565c0` = 男子／赤 `#b71c6e` = 女子）、カード左5pxライン、🔵🔴チップ
- 日程は競技No.・開始予定時刻・学年区分・申込件数・組数。休憩と昼休みの位置も入っている
- 組・レーンは**予想**。エントリータイム順・10レーン想定で、第1組＝最も遅い組、組内は速い順に 4→5→3→6→2→7→1→8→0→9
- 当日プランは選手を選ぶと、その子のレース予定時刻から補食・招集・ダウンを逆算して1日ぶん並べる

## この大会の特徴：合同レース

「小学3年生以下、4年生、5年生、6年生の区分別で行い、レースは『4年生以下』『5・6年生』で行う」。
**クラス区分は4つあるが、実際に泳ぐレースは2本**で、競技No.も1レース＝1つ（全40）。

- 組数は 4年生以下（3年生以下＋4年生）／5・6年生（5年生＋6年生）を**合算してから ÷10 の切り上げ**
- **順位・賞状は学年区分ごと**。同じ組で先にゴールした人がいても、区分が違えば順位は別に付く（3位までに賞状、表彰式は無し）

## データの出どころ

- エントリー一覧PDF（2026-08-22公開・18ページ）… 1〜17ページが個人、18ページ目が「チーム一覧」＝リレー
- 競技順序（2026-09-10版）… 競技No.1〜40・開始予定時刻・組数・休憩
- 大会要項（2026-07-18公開）… 種目・レーン数・クラス区分

エントリーPDFは座標パース。○印の**番号がクラス区分**（01:3年生以下／02:4年生／03:5年生／04:6年生／05:共通）、
○印の**x座標が種目**（自由形／背泳ぎ／平泳ぎ／バタフライ／個人メドレー）。

## 性別について

エントリー一覧PDFに性別欄が無いため、**所属ごとに男子が学年降順→女子が学年降順**という並び順から判定した。
学年が上がらず切れ目が出ない6団体だけ、氏名から境界を決めている。裏取りは2つ。

1. リレーの「チーム一覧」には性別があるので、*女子リレーを申し込んだ団体には女子が4名以上いる*ことを全団体で検算
2. 公式の参加者数（男子140・女子117）と全40レースの組数に合うかを検算

2の検算で1名ずれが見つかり、公認記録データベースの選手検索（性別で絞り込める）で
**岡島結（エイＳＳ・小4）＝男子** と確定して直した。名前の印象だけで決めない。
